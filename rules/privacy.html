Privacy Policy

Shopping channel rule service · Version 1.0, effective 27 August 2026

This service exists to hand out a file. It has no account, no form and no way to write, so the short version is that it receives nothing from your shop.

1. What the plugin sends

Nothing about your shop. The request asks for a file by name. It carries no product data, no customer data, no order data, no site address, no licence key and no identifier of any kind. The plugin sends no request body and sets no cookie.

2. What any web request carries

As with any request to any website, our host (GitHub, Inc., serving these pages through GitHub Pages) sees the connecting IP address, the time, the path requested and the user agent string. We do not receive that data as a report, do not combine it with anything else, do not attempt to identify a person or a shop from it, and do not sell or share it. GitHub's handling of it is described in the GitHub Privacy Statement.

3. What we store

No database and no user records. We keep no logs of who fetched the file.

4. Cookies and tracking

None. No cookies, no analytics, no advertising identifiers, no profiling.

5. Your rights

If you believe we hold data about you and want it looked into, write to the address below and we will answer within five business days.

6. Changes

If this policy changes we will update the version and date above.
