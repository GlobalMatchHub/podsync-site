Shopping channel rule service

Used by the Podsync AI Product Feed Auditor plugin for WooCommerce

This address hands out one file: the list of what each shopping channel asks of a product. The plugin checks a shop against that list before anything is sent to a channel.

Channel requirements change a few times a year. Keeping them in a fetched file means a change on a channel's side does not have to wait for a plugin release.

What is served

  • /rules/rules.json — the requirements.
  • /rules/rules.json.sig — a detached Ed25519 signature over that exact file. The plugin refuses any file whose signature does not verify against a public key compiled into it, so a file served from here cannot change what a shop believes unless we signed it.

What is not here

There is nothing to sign in to and nothing to send. The plugin's request carries no shop data and no identifier of any kind.
